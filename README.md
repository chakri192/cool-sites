# cool-sites

A list of fun and interesting websites, sorted by category.

**Live: [chakri192.github.io/cool-sites](https://chakri192.github.io/cool-sites/)**

## Sites

| Category | Sites |
|---|---|
| Interactive | Neal.fun, Quick Draw!, Akinator |
| Music | Radio Garden, Patatap |
| Explore | GeoGuessr, 100,000 Stars |
| Weird | The Useless Web, Scream Into the Void |
| Creative | This Is Sand |
| Science | This Person Does Not Exist, Loopy |
| Tech | WebGL Fluid Simulation, The Evolution of Trust, Parable of the Polygons, Google Experiments, Shadertoy |

Use the buttons at the top to filter by category. Hover a site to read its full description.

## Run locally

It's a single HTML file. Clone the repo and open `index.html` in a browser:

```sh
git clone https://github.com/chakri192/cool-sites.git
cd cool-sites && open index.html
```

## Add a site

1. In `index.html`, copy one of the `<a class="site-item">` blocks.
2. Change the link, name, description, domain, `data-cat`, and badge.
3. Replace the SVG icon.
4. Update the site count in the filter bar.
